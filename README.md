# Java_practice

This repository contains my Java practice work for strengthening core programming, data structures, algorithms, and interview problem-solving skills.

I use this repo to regularly solve and revise Java questions across different topics. It is meant to show my learning progress, coding consistency, and hands-on practice with common problems asked in technical interviews.

## What I Practiced

- Core Java syntax and control flow
- Arrays, strings, and basic problem solving
- Searching and sorting algorithms
- Recursion and mathematical programming problems
- Two pointer and sliding window techniques
- Arrays and hashing problems
- Linked list basics
- Pattern-printing logic
- Exception handling fundamentals

## Repository Structure

- `InterviewPrepQuetions/` - interview basics like Fibonacci, factorial, palindrome, prime number, FizzBuzz, Armstrong number, swap logic, and string reversal.
- `Notout150/` - DSA practice organized by patterns such as arrays and hashing, two pointers, sliding window, and linked lists.
- `Sorting/` - implementations of common sorting algorithms including bubble sort, insertion sort, selection sort, merge sort, and quick sort.
- `Searhing/` - linear search and binary search practice.
- `StringManipulation/` - string-based problems such as reverse vowels, brackets, repeated substring checks, and longest common prefix.
- `StringBuilder/` - practice with Java `StringBuilder` and related APIs.
- `StarPatterns/` - pattern-printing exercises to improve nested loop logic.
- `ExceptionHandling/` - basic Java exception handling examples.
- `ExtraPractice/` and `PractriceQuetions/` - additional problems solved during practice.

## Skills Demonstrated

- Writing Java programs from scratch
- Breaking problems into smaller logical steps
- Using loops, conditionals, arrays, strings, and methods effectively
- Practicing time and space complexity awareness
- Organizing solutions by topic
- Building consistency through repeated coding practice

## How to Run

Most files are standalone Java programs. Open any `.java` file in an IDE or compile it from the terminal.

Example:

```powershell
cd Sorting
javac Bubble.java
java Bubble
```
